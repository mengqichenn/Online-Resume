# Online-Resume


## 📌 About the Project

This project is my first introduction to web development using **HTML and CSS**.

As part of my transition into computer science, I created this personal portfolio to practice the fundamentals of web development while presenting my background, professional experiences, skills, and interests.

The website is built with basic HTML and CSS, with a focus on page structure, styling, layout, and responsive design.

## 🛠️ Technologies Used

- **HTML5** — Page structure and content
- **CSS3** — Styling, layout, and responsive design

## 🌐 Features

- Personal introduction and background
- Professional experiences and education
- Technical and soft skills
- Current status and future objectives
- Contact section with a form powered by Formspree
- Responsive layout for different screen sizes

## 🚀 Getting Started

To run the website locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/mengqichenn/online-resume.git
   ```
2. Open the project folder.
3. Open `index.html` in your web browser.

No additional installation is required.
